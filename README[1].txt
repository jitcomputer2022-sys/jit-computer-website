JIT COMPUTER – WEBSITE PUBLISHING FILES

Files:
- index.html : Complete responsive Gujarati website.

How to publish on Cloudflare Pages (Direct Upload):
1. Extract this ZIP file.
2. In Cloudflare Pages choose Direct Upload / Upload assets (not GitHub).
3. Upload the index.html file or the extracted folder containing index.html.
4. Deploy the site. The root of the uploaded site must contain index.html.
